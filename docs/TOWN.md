# 街並みの生成

`mcblueprint spec-template town --minecraft-version 1.21.11` の雛形を保存し、
`mcblueprint make town.yaml` で生成する。`city` も同じ planner を使う。
様式は同梱の `medieval.town` layout がある medieval に対応する。

`features.buildings` は独立した区画内の建物群数。要求数を削減しない。
間口・奥行き・道路幅は layout の範囲から決め、収容不足は Site で拒否する。
最小規模でも道路と公共空間の余裕が必要なため、まず medium 以上を使う。
8建物の固定課題は medium/huge、seed 42/73/101 を使う。
huge では L/T 型を含み、狭い区画では矩形棟を使う。

区画は主要道に面した帯を分割する。広い区画では矩形棟を接合した L/T 型を
割り当て、階数と用途を変える。`house#1` 以降は矩形棟の安定IDなので、
L/T 型では1区画に複数IDが属する。入口と各階到着点、道路・接合通路を
内部計画 v2 の接続グラフへ保存する。外部の BuildSpec/scene/edits は v1 のまま。

道路は heapq の A* で地表の勾配にコストを付け、水域と通行禁止列を全幅で避ける。
建物外形を予約し、各入口への枝道を接続する。生成地形の街区を共通床高へ造成し、
元地形高は Weather の基準場として保持する。施工は既存 path、踊り場の工学規則は
surface_path と共有する。井戸と市場は中央の公共空間へ置く。
`plaza`/`well`/`market` は個別に省略できる。

接合後の露出面で既存 Detail を再実行し、共有構造・通路・屋根へ移される高さを
装飾候補から除く。各建物群で階数を変え、L/T 型の内部は同じ階数で構成する。
個別棟の階数編集にも対応し、接合部へ移した支持柱を構造・露出外壁の両方で評価する。

既存 snapshot の街並み配置と洞窟は対象外。公共空間を含む造成範囲の水域や道路の行止まりはエラーにし、
水を盛土で埋めたり、建物を減らしたりしない。

区画分割は `mcblueprint.parcels.split_frontage` にあり、地上・地下に依存しない。
入力は閉区間の矩形と layout の寸法範囲、戻り値は非重複の矩形区画列。
接道・保護域・建物外形の検査は呼出し側で行う。
